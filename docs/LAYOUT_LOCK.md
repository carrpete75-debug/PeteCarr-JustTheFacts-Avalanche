# Layout lock (Avalanche Desk, launched 2026-10-01)

Built from the approved Nuggets Desk layout, which was itself cloned from the Broncos Desk (locked 2026-09-23). Don't redesign without an explicit user request. Daily runs change content only, unless they're fixing a real bug.

1. **Banner**: compact, centered CSS-text `.avalanche-banner` (COLORADO AVALANCHE / silver rule / JUST THE FACTS, with burgundy corner accents and a thin silver stripe) above the brand/nav row. Not image-based; not 2× height.
2. **Rail + main**: full-width, flush-left `.page-shell`, with `.central-rail` beside `<main>` (`clamp(15rem, 20vw, 19.5rem)`, ~1.05rem type, ~0.4rem left pad), flush to the left edge of the burgundy page.
   - Tile 1, `aside.central-standings`: Central Division standings (8 teams), in the NHL's `divisionSequence` order. Columns: Team / W–L–OT / PTS. The Avalanche row is `tr.is-col`. The title links to nhl.com division standings (new tab).
   - Tile 2, `aside.central-standings.central-standings--odds`: Team / Div / Cup American odds (Avalanche row `is-col`), sorted by Div odds, with a muted source line naming the book and an "as of" time in MT. 0.75rem gap under tile 1.
3. **Chrome / palette** (`:root` in styles.css): page `--burgundy #6F263D`; white tiles; header, footer and table heads `--navy #111C2E`; links and pills `--steel #236192`; banner rule and quiet borders `--silver #A2AAAD`; highlight rows `--steel-soft #eaf1f8`; badge text `--burgundy-deep`; `--accent` (burgundy) for kicker and hover. **Never use silver as text on white** (contrast too low).
4. **Card order in `.grid`**:
   1. Record (span-2, with a last-game/last-season writeup)
   2. Last game (span-2: period line score table, scorers, goalies, closing DK line)
   3. Next | Sportsbook odds (one column each)
   4. Kalshi (span-2, kept separate from sportsbooks)
   5. Injuries (span-2)
   6. Upcoming (span-2, next ~6 games; every row ends with an `a.ticket-link` pill, see rule 8)
   7. Ball Arena & team news (span-2)
   8. Stanley Cup odds, top 5 West / top 5 East (span-2)

   No weather card.
5. **Honesty rule**: never make up a figure. If a number isn't available, say so on the card with `<span class="unavail">…</span>` (e.g. "Lines not posted yet"). Every card ends with a `.source-row`. Odds and markets carry an "as of" time in MT.
6. External links use `target="_blank" rel="noopener noreferrer"`. Same-site links stay relative. No JavaScript.
7. **Archive**: freeze the previous home page to `docs/archive/YYYY-MM-DD.html`. Rewrite paths to `../styles.css?v=…` and `../index.html`, `../hall-of-fame.html` etc., and remove `aria-current` from the snapshot's nav. Add a `<li>` at the top of the list in `docs/archive/index.html`, below the `<!-- ARCHIVE:list -->` marker, and delete the "No archived editions yet" placeholder the first time. Never overwrite an existing archive file.
8. **Ticket links**: every upcoming game row (home Upcoming card and schedule page) ends with `<a class="ticket-link" href="…" target="_blank" rel="noopener noreferrer" aria-label="Tickets: …">Tickets</a>`. The URL comes only from the game's `ticketsLink` in the NHL schedule API:
   - Home games: the Avs' `avs.social/...` short link, resolved to its Ticketmaster `/event/<id>`.
   - Road games: the host team's Ticketmaster link.
   - Strip `utm_*`, `wt.mc_id` and `camefrom`; never change the event ID.
   - If there's no `ticketsLink`, use the host team's official `https://www.nhl.com/<team>/tickets`.
   - Never guess event IDs; never use resale or affiliate links.
   - Ticketmaster answers bots with 401/403, so a link counts as verified when it came verbatim from the NHL schedule data for that exact game.
9. **Custom domain**: `docs/CNAME` (`avs.petecarr.com`) must stay in the repo.
10. **Site nav**: every page's `nav.nav` has exactly five links, in this order: **Home, Schedule, Roster, Archive, Hall of Fame**.
    - Paths are relative: `index.html` / `schedule.html` / `roster.html` / `archive/index.html` / `hall-of-fame.html` from the docs root; `../index.html` / `../schedule.html` / `../roster.html` / `index.html` / `../hall-of-fame.html` from `docs/archive/`.
    - The current page carries `aria-current="page"`.
    - The shared header, nav and footer markup lives in `tools/site_chrome.py`. The generators and the archive page use it, and the home page must match it.
    - The stylesheet link is `styles.css?v=avs-1` (`../styles.css?v=avs-1` in archive/). Bump `CSS_VERSION` in site_chrome.py, and the version on every page, only when styles.css changes.
11. **Schedule page** (`docs/schedule.html`): generated by `python3 tools/build_schedule.py` from `api-web.nhle.com/v1/club-schedule-season/COL/now`, using `tools/schedule_template.html`.
    - Layout: no rail. Hero first, then one `section.card.sched-month` per group: Preseason first, then each regular-season month, then Postseason. A closing "Sources & notes" card ends the page.
    - Columns: Date (MT) · Opponent (`vs`/`@`) · Venue · Time (MT) / result · TV (US) · Tickets.
    - Home rows are `tr.is-home`.
    - Results show W / L / OTL / SOL plus the score (Avs first), then the running W–L–OT record. Preseason and regular-season records are counted separately.
    - Writes `/workspace/avalanche-data/schedule-YYYY-MM-DD.json`.
12. **Roster page** (`docs/roster.html`): generated by `python3 tools/build_roster.py`, using `tools/roster_template.html`.
    - Data: the NHL active roster (`roster/COL/current`) plus NHL club stats, cross-checked against ESPN's roster. ESPN players who aren't on the NHL roster but carry an ESPN injury go in an "Injured reserve / non-roster" group. Any other disagreement exits with `ROSTER MISMATCH`; use `--allow-mismatch` only after a real, verified transaction, and the page then lists the mismatch.
    - Groups: Forwards → Defense → Goalies, sorted by number.
    - Cards after the table: Coaching staff → Injury report → Sources & notes.
    - Writes `/workspace/avalanche-data/roster-YYYY-MM-DD.json`.
13. **Hall of Fame page** (`docs/hall-of-fame.html`): STATIC. It is generated once, outside the repo, by `/workspace/avalanche-hof-draft/build.py` (copy its output into docs).
    - Daily runs never edit, regenerate, re-date or reorder it, and never add or remove inductees. The only allowed change is keeping its shared nav and header in sync when `site_chrome.py` changes, and that is done by re-running the generator.
    - Content changes (new inductees, an active player retiring, stat refreshes) happen only on an explicit user request. Verify every fact against NHL.com, Hockey-Reference or the Avalanche site, and give every entry a source line.
    - Structure: hero (kicker "Franchise history"), then section cards in this order: "Retired numbers", "Strong cases", "Coaches wing", "Executive wing", "Active: nominated now, inducted on retirement". Claude Lemieux sits in Strong cases (no separate wing). Current total is 22 cards for 21 people: 6 retired numbers, 9 strong cases, 3 coaches (Crawford, Hartley, Bednar), 2 executives (Lacroix, Sakic) and 2 active. Joe Sakic appears twice; his player card (`#sakic-player`) and executive card (`#sakic-exec`) link to each other. Each holds `article.hof-entry` items, and each card ends with a `.source-row`. Stats are Colorado era (1995–96 on); Quebec Nordiques years are listed separately.
