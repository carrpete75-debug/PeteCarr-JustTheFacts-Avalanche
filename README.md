# Just the Facts — Avalanche

A small static site with a daily, unofficial Colorado Avalanche briefing (Avalanche Desk). It's a sibling of the Broncos and Nuggets desks.

- Live: https://avs.petecarr.com (custom domain), served by GitHub Pages from `main` / `docs`
- Plain HTML and CSS, no JavaScript and no build step for the published files. Layout rules: `docs/LAYOUT_LOCK.md`

## Layout

```
docs/
  index.html          daily home briefing (rewritten each morning, content only)
  schedule.html       generated by tools/build_schedule.py
  roster.html         generated by tools/build_roster.py
  archive/index.html  list of frozen past home pages (archive/YYYY-MM-DD.html)
  hall-of-fame.html   STATIC franchise Hall of Fame (22 cards / 21 people); never touched by daily runs
  styles.css          Avs palette via :root variables
  CNAME               avs.petecarr.com (must stay)
tools/
  site_chrome.py      shared header / nav / footer markup + stylesheet version
  build_schedule.py   NHL schedule API -> docs/schedule.html (+ ticket links)
  build_roster.py     NHL roster + club stats, ESPN cross-check -> docs/roster.html
  *_template.html     page templates used by the generators
```

## Data sources

| Section | Source |
|---|---|
| Schedule, results, US TV, ticket links | `https://api-web.nhle.com/v1/club-schedule-season/COL/now` |
| Central standings | `https://api-web.nhle.com/v1/standings/now` |
| Last game | `https://api-web.nhle.com/v1/gamecenter/{id}/boxscore`, `/landing`, `/right-rail`; ESPN `summary?event=` for the AP recap and DraftKings line |
| Roster / stats | `https://api-web.nhle.com/v1/roster/COL/current`, `/v1/club-stats/COL/now`; ESPN roster cross-check |
| Injuries | ESPN `sports.core.api.espn.com/v2/sports/hockey/leagues/nhl/teams/17/injuries` |
| Game lines | ESPN NHL scoreboard / summary `pickcenter` (DraftKings) |
| Futures | `https://www.espn.com/nhl/futures` (+ `/_/group/conference`); Central division via VegasInsider |
| Kalshi | `https://api.elections.kalshi.com/trade-api/v2` (`KXNHLGAME`, `KXNHL-27`, `KXNHLWEST-27`) |

## Daily update

1. `git pull origin main`
2. Freeze the current `docs/index.html` to `docs/archive/YYYY-MM-DD.html` and add a line at the top of `docs/archive/index.html`
3. `python3 tools/build_schedule.py` and `python3 tools/build_roster.py`
4. Rewrite `docs/index.html` content from a fresh fact pack (layout locked)
5. Commit "Daily Avalanche briefing Mon DD: …" and push to `main`
